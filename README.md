# Two Boots

Сайт-витрина бренда экипировки для фигурного катания: чехлы для лезвий, сумки и чемоданы, скакалки и аксессуары.

## Что это

Одностраничное приложение без сборки и зависимостей — весь сайт лежит в одном файле `index.html`
(разметка, стили и скрипты внутри). Открывается двойным кликом, никакой установки не требуется.

## Страницы

Навигация работает на hash-роутинге, перезагрузки страницы не происходит.

| Раздел | Адрес | Что внутри |
| --- | --- | --- |
| Главная | `#/` | Хиро-блок, категории, хиты каталога, преимущества |
| Каталог | `#/catalog` | 12 товаров, фильтр по четырём категориям |
| Товар | `#/product/:id` | Описание, характеристики, выбор размера и количества, похожие модели |
| О бренде | `#/about` | История, принципы, этапы производства |
| Контакты | `#/contact` | Контакты, форма обратной связи, частые вопросы |

Фильтр каталога отражается в адресе (`#/catalog?cat=ropes`), поэтому ссылкой на категорию можно делиться.

## Возможности

- Корзина: добавление с карточки и со страницы товара, счётчик, удаление, боковая панель с итогом
- Светлая и тёмная тема — подхватывается из настроек системы
- Адаптивная вёрстка, отдельное полноэкранное меню на мобильных
- Никаких внешних зависимостей, кроме шрифтов Google Fonts

## Оговорки

Это демонстрационная витрина. Оформление заказа и отправка формы не подключены к бэкенду —
обе кнопки показывают уведомление и ничего не отправляют. Товары, цены и контакты вымышленные.

## Как редактировать

Каталог задан массивом `PRODUCTS` в `index.html` — товар описывается идентификатором, категорией,
названием, ценой, описанием и списком характеристик:

```js
{id:'basic-jump', cat:'ropes', name:'Скакалка для разминки Basic Jump', price:890,
  desc:'Простая и лёгкая скакалка для разминки перед тренировкой на льду.',
  specs:[['Трос','ПВХ'],['Длина','регулируется под рост'],['Вес','лёгкая']]},
```

Категории перечислены в объекте `CATEGORIES`, иконки — в `ICONS`, фирменные цвета и шрифты —
в CSS-переменных в начале файла (блок `:root`).

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если нужен локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.
